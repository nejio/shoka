# 書架 — 書斎(積読)の刷新 v11

## 思想

積読は「消化すべき負債」ではなく、**関心の地図・知の環境**である。
読まなくてもよい。積まれていること自体に意味がある。
この考えに沿って、積読を本棚から独立させ、圧をかけない設計に作り直した。

## 変更点

### 1. 「書斎」タブを新設(4タブ構成)
暦・統計 / 本棚 / **書斎** / 記録

本棚タブからは積読の山を撤去。本棚は読了の棚だけに戻り、圧迫が解消。

### 2. 関心の地図
書斎タブは、積読を**タグごとの群れ**として並べる。冊数の多い順=関心の強い順。
書影があればタイル、なければタグ色の背表紙風タイル。
眺めることで「いま自分がどこに関心を向けているか」が分かる。

### 3. 見送り(積まない自由)
詳細画面の「いまは見送る」で、蔵書には残したまま地図から退かせる。
書斎タブ下部の「見送った本」に薄く格納され、「関心の地図に戻す」でいつでも復帰。
削除ではないので、関心の変遷そのものが記録として残る。

### 4. 想起の仕掛け(静かな表示のみ・通知なし)
- **今日の一冊**: 暦・統計タブの下部に、積読から日替わりで1冊を静かに表示。
  同じ日なら何度開いても同じ本(気まぐれに変わらない)。
- **読了直後の想起**: 本を読み終えた瞬間、同じタグの積読があれば
  「書斎に『歴史』の本が3冊あります」と一度だけ通知。次の関心が高まる瞬間を狙う。

### 5. 積んだ文脈の記録
積読には「積んだ日」が自動で記録され、「**なぜ気になったか**」を書き留められる
(登録時、または詳細画面からいつでも追記・編集可)。
数か月後に見返したとき、過去の自分の関心が蘇る。

### 6. 見送り本の重複対応
見送り中の本を再登録しようとすると、新規作成せず自動で復活する。
- 積読として追加 → 「関心の地図に戻しました」
- 読んでいるで追加 → そのまま読書中へ
- 読み終えたで追加 → その本を読了化

## デプロイ
`bundle.js?v=11` / `sw.js VERSION="v11"`。
zipを作業フォルダに上書き → `npm run build` → 3ファイルをアップロード。

## スモークテスト
- [ ] 下タブが4つになり「書斎」が開く
- [ ] 積読を数冊登録 → タグごとの群れとして並ぶ
- [ ] 登録時に「なぜ気になったか」を書ける / 詳細から後で追記できる
- [ ] 詳細の「いまは見送る」→ 地図から消え、「見送った本」に入る
- [ ] 「関心の地図に戻す」で復帰する
- [ ] 暦・統計タブの下に「今日の一冊」が出る(同じ日は同じ本)
- [ ] 本を読了 → 同じタグの積読があれば通知が出る
- [ ] 本棚タブに積読が表示されない(読了の棚のみ)
