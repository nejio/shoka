# 書架 — 起動時に「書架」の画面から進まない問題 v27

## 症状
AndroidのChrome(PWA)で開くと、中央に「書架」と出たまま止まる。
Chromeのキャッシュを消すと直るが、時間が経つとまた再発する。

## 原因1: オフライン保存の占有方式(設計ミス)

Firestoreのオフライン保存を **`persistentSingleTabManager`(単一タブ方式)** で
設定していた。これは保存領域を**1つのインスタンスだけが占有する**方式で、
次の場合に占有権が残ったままになる。

- PWAとブラウザのタブで同時に開いた
- Androidがメモリ不足でPWAを強制終了した(正常な終了処理を経ない)

占有権を取得できないインスタンスは保存領域を読めず、
データの購読(`onSnapshot`)が応答しないまま止まる。

キャッシュを消すと保存領域ごと消えて占有権も解放されるため一時的に直り、
しばらく使うとまた同じ状態に陥る。報告された症状と一致する。

### 対応
**複数タブ方式(`persistentMultipleTabManager`)に変更**した。
インスタンス間で調停されるため、同時に開いても強制終了されても占有権は残らない。

あわせて、端末側の事情でオフライン保存自体が初期化できない場合にも、
保存を諦めるだけでアプリは起動するようにした(従来は起動不能になり得た)。

## 原因2: 読み込みに失敗すると脱出できない(設計ミス)

より深刻なのはこちら。

```
if (books === null) { 「書架」の画面を返す }   ← ここで終わり
... エラー表示 ...                              ← ここまで到達しない
```

読み込みが失敗しても、判定順の都合で**エラーも再試行手段も表示されず**、
利用者は永久に「書架」の画面から動けなかった。
原因が何であれ行き止まりになる作りだった。

### 対応
読み込み中の画面を作り直した。

- **6秒経っても終わらない**、または**エラーが起きた**場合に、
  状況の説明と「読み込み直す」「サインアウト」を表示する
- エラー内容も画面に出す(原因の切り分けができるように)
- 認証待ちの画面にも同じ仕組みを入れた

これで、何が起きても操作不能のまま取り残されることはなくなる。

## デプロイ
`bundle.js?v=27` / `sw.js VERSION="v27"` / 設定画面の表示 `v27`。

```
bundle.js
index.html
sw.js
```

## 確認
1. 設定画面の下部が **v27** になっていること
2. しばらく使ったあと、時間を空けて開き直しても起動すること
3. (再現する場合)「書架」の画面で6秒待つと、
   エラー内容と「読み込み直す」が表示されること

※ 3で表示されたエラー文言を教えてください。
　 原因1で解消していない場合、その文言で次の原因を特定できます。
