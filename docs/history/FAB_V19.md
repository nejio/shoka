# 書架 — 本の追加の入口を一本化 v19

## 問題

「＋ 本を追加」への入口が2か所にあった。

1. 記録タブの上部ボタン … **画面上部で親指が届かない**
2. FABシートの下部 … 押しやすいが、読書中の本が増えると下に押し出されて見えなくなる

結果、押しにくい方(上部)を使うことになっていた。

## 修正

入口をFABに一本化した。

### FABシートの構造を3層に固定

```
FAB「記録」をタップ
  ┌────────────────────┐
  │ 今日の記録            │ ← 見出し(固定)
  ├────────────────────┤
  │ 読書中①  [p.__][保存] │
  │ 読書中②  [p.__][保存] │ ← ここだけスクロール
  │ 読書中③  [p.__][保存] │
  ├────────────────────┤
  │   ＋ 本を追加         │ ← 下端に固定
  └────────────────────┘
```

読書中が何冊あっても「＋ 本を追加」は常に同じ位置(親指が届く下端)にある。

### 記録タブ上部のボタンを撤去

重複が消え、「FAB → 下端の追加」という単一の動線になった。

## なぜスピードダイヤルにしなかったか

FABタップで「進捗を記録」「本を追加」の2択を出す案は却下した。
最も頻度が高い操作は**進捗記録**(通常のペースなら毎日)で、本の追加は数日〜数週に1回。
2択を挟むと日常操作が1タップ増えて損をする。
現在のシートは1タップで進捗入力欄に到達できる形を保っている。

## 蔵書が空のときの配慮

記録タブに何も表示されなくなるのを防ぐため、
蔵書が0冊のときだけ「最初の一冊から、歴史が始まります。/ 右下の「記録」から本を追加できます。」
という案内を出す。FABの存在に気づけるようにするため。
