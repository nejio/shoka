# 書架 — 書斎の重複解消 v15

## 問題

複数タグ(特に二層構造で細分を選ぶと親が自動で付く)により、
関心の地図に同じ本が何度も現れていた。
「小説30冊」と「SF12冊」が並び、後者は前者の部分集合という状態。

原因は、**1つの表示に2つの役割を負わせていた**こと:
- 関心の分布を見る(重複が意味を持つ統計)
- 蔵書を眺める(1冊は1回であるべき目録)

## 解決

役割を分離した上で、二層タクソノミーをそのまま視覚構造にした。

### 1. 分布バー(統計)
地図の冒頭に、大分類ごとの構成比を帯グラフで表示。
本は1冊1回で数えるので、幅の合計は必ず100%になる。
凡例に冊数、その下に「ほかに重ねているタグ」として副次的な関心も併記。

### 2. 階層表示(目録)
各本は**主タグの大分類に1回だけ**現れ、その内側で細分ごとに整列する。

```
小説  30冊                    ← 折りたためる
  ├ SF・ファンタジー  12冊    [タイル×12]
  ├ ミステリ・サスペンス 8冊  [タイル×8]
  └ 細分なし          10冊    [タイル×10]

経済・経営  14冊
  ├ 金融・投資  6冊
  └ 細分なし    8冊
```

「小説を30冊積んでいて、うちSFが12冊」という入れ子の関係が、
そのまま入れ子で見える。重複は消え、情報量は減らない。

### 3. 折りたたみ
大分類の見出しをタップで開閉。縦に伸びる問題に対応。

## 配置ルール

本がどの群れに入るかは次の順で決まる:
1. タグの中の最初の**大分類**(主タグ優先)
2. 大分類がなければ、細分から親を辿る(例: 金融・投資だけ → 経済・経営)
3. どちらもなければ、そのタグ自体を独立した群れにする(自作タグ・旧タグ)

群れの中の細分は、その大分類に属する細分のみ。
それ以外のタグ(「海外」「中国」など)は分布バーの
「ほかに重ねているタグ」に集計される。

## デプロイ
`bundle.js?v=15` / `sw.js VERSION="v15"`。

## スモークテスト
- [ ] 地図の冒頭に分布バーが出て、幅の合計が100%になっている
- [ ] 同じ本が2回以上現れない
- [ ] 細分を持つ本が、大分類の内側の細分ブロックに入っている
- [ ] 細分なしの本が「細分なし」にまとまっている
- [ ] 大分類の見出しをタップで開閉できる
- [ ] 自作タグだけの本が独立した群れになる
- [ ] 「ほかに重ねているタグ」に副次タグが出る
