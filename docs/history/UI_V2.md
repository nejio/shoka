# 書架 — UI大型アップデート(v5)

## 変更内容

### 1. 下タブナビゲーション
タブ(暦・統計 / 本棚 / 記録)を画面下部に固定。親指で届く位置に。

### 2. フローティング「記録」ボタン(FAB)
全画面の右下に金色の「記録」ボタン。押すとシートが開き:
- 読書中の本が一覧され、**その場で到達ページを入力して保存**(どの画面からでも2タップ)
- 「＋ 本を追加」で記録タブのフォームへ直行

### 3. 読書暦を縦型に刷新
- 週=1行、**最新週が最上段**(今日が常に見える。横スクロール廃止)
- 月の変わり目にラベル、曜日ヘッダー付き、今日は金枠
- 過去は「さらに過去を見る(+12週)」で下に伸びる

### 4. テーマ切替(白・黒・書斎)
ヘッダー右のボタンでサイクル切替。選択は端末に記憶。
- 白: 従来の紙色
- 黒: OLED向けダーク
- 書斎: 焦茶の木質(テクスチャ画像なし、濃淡の意匠で表現)

### 5. 統計の自動適応(モード切替の代替)
直近60日の読了ペースから表示の主役を自動判定:
- 月10冊以上 → 冊数中心(今月◯冊 / 月別読了数を上に)
- それ未満 → ページ・読書日中心(今月の読書日 / 今月◯p / 日別ページ数を上に)
統計タブ右上の「自動・冊・頁」で手動固定も可能。

## デプロイ
`bundle.js?v=5` / `sw.js VERSION="v5"` に更新済み。
```bash
npm run build
findstr "YOUR_API_KEY" bundle.js   # 何も出なければOK
# bundle.js, index.html, sw.js を再アップロード
```
