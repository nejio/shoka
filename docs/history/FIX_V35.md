# 書架 — 2件の不具合修正 v35

## 1. 評価なしで読了すると星1つになる

### 原因(私のミス)
v29で「未評価を許容する」と直したつもりが、逆に悪化させていました。

```js
let rating = Math.round(Number(input.rating));
rating = Number.isFinite(rating) ? Math.min(5, Math.max(1, rating)) : null;
```

**`Number(null)` は `0` になり、`Number.isFinite(0)` は true** です。
そのため null を渡すと 0 として通過し、`Math.max(1, 0)` で **1 にクランプ**されていました。

登録フォームは未評価のとき明示的に `null` を送るので、
**必ず星1つが付く**状態でした。星3の既定値より明確に悪い挙動です。

### 修正
評価の正規化を専用の関数に切り出し、
`undefined / null / 空文字 / 0 / 負数` をすべて **未評価(null)** として扱います。

同じ処理が `books.js` の評価更新にも重複していたため、共通化しました。
実装が2箇所にあると、片方だけ直して食い違う温床になります。

テストで全パターン(`undefined, null, 0, "", -3, "4", 9`)を固定しました。

## 2. 1日に2冊以上読了すると、暦で1冊しか出ない

### 原因(私のミス)
日別の記録が**読了を単数のスロット**で持っていました。

```js
at(b.end).finish = b;   // 後から処理された本で上書きされる
```

同じ日に複数冊読み終えると、最後の1冊しか残りませんでした。

### 修正
読了を**配列**に変えました(`finished: [book]`)。

暦のマスをタップしたときの挙動も変えています。

- **1冊なら** … これまで通りその本の詳細が開く
- **複数冊なら** … その日の一覧が開き、どれを見るか選べる
  (「読了」「読んだ日」の区別も表示)

複数冊ある日は、マスの**右下が少し欠けた形**になるので、
タップする前に見分けられます。
