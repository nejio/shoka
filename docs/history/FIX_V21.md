# 書架 — 修正 v21

## 1. 【バグ修正】追加フォームが開きっぱなしになる

### 症状
一度「本を追加」を押すと、「やめる」で閉じても、
別のタブに移動して記録タブに戻るたびにフォームが再び開き、
書名欄にフォーカスが当たってキーボードが出てしまう。

### 原因
フォームを開く指示を `addSignal` というカウンター(数値)で渡していた。
タブを切り替えると記録タブのコンポーネントは破棄され、戻ると作り直される。
そのとき「`addSignal > 0` なら開く」という判定が**再実行される**ため、
一度でも押していれば毎回開いてしまっていた。

### 修正
フォームの開閉状態を親(アプリ本体)が持つ真偽値に変更し、
**記録タブ以外へ移動した時点で閉じる**ようにした。
これにより、戻っても開きっぱなしにならない。

あわせて**書名欄の自動フォーカスを解除**した。
フォームを開いた直後にキーボードが画面を覆うと、
上部にあるバーコード・検索ボタンが隠れて使いにくいため。
(進捗記録のページ数入力は、目的が明確なので自動フォーカスを残している)

## 2. 「書斎」テーマの削除

見にくいとのことで削除。テーマは **白 / 黒** の2種になった。
既に「書斎」を選んでいた場合は自動的に白に戻る。

## デプロイ
`bundle.js?v=21` / `sw.js VERSION="v21"`。
**index.html にテーマのCSSが入っているため、index.html のアップロードを忘れずに。**
