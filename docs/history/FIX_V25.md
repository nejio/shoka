# 書架 — 表示の修正 v25

## 1. 「今月の読書日」が途中で折り返される

### 環境依存でした
カードは画面幅の1/4なので、端末の横幅とフォントで折り返し位置が変わります。
しかも「今月の読書 / 日」と語の途中で切れていました。

### 修正
**改行位置をコードで固定**しました(画面幅任せにしない)。

- 「今月の / 読書日」
- 「今月の / 頁数」 ← 従来「今月」だけで、何の数字か分からなかったのも直しました

あわせて、ラベル領域に2行ぶんの高さを常に確保し、
1行のカードと2行のカードで数値の高さが揃うようにしました。

## 2. 月表示が「8月」「8月」と重なる

### 原因
「月初(1日)を含む週に印を出す」規則と「最上段に現在の月を出す」規則が
両方はたらき、同じ月が2行に出ていました。

### 修正
規則を一本化し、**行の月が変わったところにだけ印を出す**方式にしました。
複数の日付(月またぎ・年またぎ・年末年始)で検証し、重複しないことを確認しています。
