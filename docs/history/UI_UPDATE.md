# 書架 — 記録UIの統合(入り口を1つに)

## 変更点

**入り口を「＋ 本を追加」の1ボタンに統合**しました。
以前の「読了を記録」「読み始めた本」の2ボタンを廃止。

フォームを開くと:
1. 書名(スキャン/検索で自動入力可)
2. 状態トグル「読んでいる / これから」(初期選択) ⇔「もう読み終えた」
3. 状態に応じた入力欄

「読んでいる / これから」で追加 → 読書中リストへ(従来通り進捗・読了記録)。
「もう読み終えた」で追加 → その場で★と読了日を付けて一発読了。

## 設計意図

読書の実態は「本を1冊迎え入れる → 読む → 読み終える」という時間の流れ。
入り口で状態を二択させるのはアプリ都合だったため、「本を追加」に一本化し、
状態は書名が決まった後に選ぶ自然な順序にしました。多数派(数日〜数週かけて読む)に
素直な初期値として「読んでいる / これから」を既定に。

一発読了する人も、トグルを1タップ切り替えるだけで手数はほぼ変わりません。

## デプロイ

`bundle.js?v=4` / `sw.js VERSION="v4"` に更新済み。

```bash
npm run build
# bundle.js, index.html, sw.js を再アップロード
```

## スモークテスト

- [ ] 「＋ 本を追加」を押すとフォームが開く(初期は「読んでいる / これから」)
- [ ] 書名を入れてそのまま保存 → 読書中に入る
- [ ] トグルを「もう読み終えた」に → ★と読了日が出る → 保存で本棚へ
- [ ] スキャン/検索での自動入力は従来通り動く
- [ ] 読書中の本の進捗・読了フローは変わらず動く
