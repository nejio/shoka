# 書架 — ビジュアルの整備 v23

アイコン・フォント・質感の3点を一度に整備した。
**画像ファイルを新たに用意する必要はなく、すべてコードで生成している**
(唯一の例外はフォント本体と、既に生成済みのアプリアイコン)。

## 1. アイコン(SVG内製)

`src/components/icons.jsx` に手描きのSVGを用意した。外部ライブラリも画像も使わない。

- **線幅を1.3に統一** … 明朝体の細い線と調和させるため。
  既製アイコン(Material等)の太く丸い線はこのアプリでは浮く
- **色は currentColor** … 白/黒テーマの切り替えに自動追従する
- **容量ゼロ** … 追加のダウンロードが発生しない

### 置き換えた箇所

| 変更前 | 変更後 | 理由 |
|---|---|---|
| 「設定」の文字ボタン | **歯車** | ハンバーガー(三本線)は「メニュー」の意味。移動は下タブが担うので誤解を招く |
| 「📷 バーコード」 | **バーコードのSVG** | 絵文字は端末ごとに絵柄が変わり、画面の中で異質だった |
| 「▾ ▸」の三角 | **シェブロン(細い山形)** | 文字記号はフォント依存。線幅も他と揃わない |

タブは文字のまま残した。明朝体で「暦・統計 / 本棚 / 書斎 / 記録」と並ぶ姿は
このアプリの品格そのもので、アイコンを足すと雑然とするため。

## 2. 明朝体の同梱

### これまでの問題
コードは `"Shippori Mincho"` を指定していたが、**どこからも読み込んでいなかった**。
そのため端末任せになり、iPhoneではヒラギノ明朝、Windowsでは游明朝、
Androidでは明朝体が存在せず**ゴシックか汎用serifに落ちていた**。
タイポグラフィで見せるアプリとしては致命的な不均一だった。

### 対応
**Shippori Mincho(SIL Open Font License)を同梱**した。

- `fonts/shippori-mincho-jp-400.woff2` … 日本語6,881字・1.3MB
- `font-display: swap` … 読込中は端末の明朝で表示し、揃ったら差し替わるので
  文字が消える時間がない
- Service Workerで**初回表示時にキャッシュ**(事前取得はしないので起動は遅くならない)。
  2回目以降は通信ゼロ、オフラインでも同じ字面
- ライセンス全文を `fonts/LICENSE-Shippori-Mincho.txt` に同梱

npmパッケージは実体を取り出したあと依存から外した(59MBあるため、
`npm install` を重くしない)。

## 3. 質感(すべてコード生成・画像不要)

いずれも「言われないと気づかない濃度」に留めた。

- **和紙の地** … SVGのノイズフィルタを背景に極薄で敷いた。
  写真テクスチャと違い拡大しても劣化せず、容量もゼロ。
  濃度はテーマごとに変数で調整している
- **背表紙の織り目** … 縦の極薄ストライプと、天(上端)の箔押し風の光沢。
  本棚の説得力が一段上がる
- **扉の副罫** … ヘッダー下の罫線に、金の細い副罫を重ねた。和書の二重罫の見立て

## 今後、画像が必要になるもの

| 用途 | 対応 |
|---|---|
| アプリアイコン | **生成済み**(作り直しも可能) |
| Playストアのフィーチャーグラフィック(1024×500) | **私が生成できます** |
| ストア用スクリーンショット | 実機の画面撮影が必要(Kenさん) |

## デプロイ

`bundle.js?v=23` / `sw.js VERSION="v23"`。

**⚠ 今回から `fonts/` フォルダのアップロードが必要です。**

アップロードするもの:
```
index.html
bundle.js
sw.js
fonts/          ← 新規(woff2とライセンス)
icons/          ← 既存(変更なし)
manifest.json   ← 既存(変更なし)
```
