# 書架 — 分野・細分の改訂 v30

大分類10 + 形式2、**細分93**(旧69)。

## 改訂の理由

前回までは、大分類はNDC(日本十進分類法)に基づく根拠があったのに対し、
**細分は書店の棚を思い出して列挙しただけ**で体系的な導出をしていなかった。
そのため化学が丸ごと抜ける、工学の居場所がないといった穴が生じていた。

## 主な変更

### 1. 小説 (6 → 11)
ジャンル小説に偏っており、いわゆる一般文芸の居場所がなかった。
**人間ドラマ / 青春・成長 / 仕事・職業 / 冒険・アクション / ユーモア** を追加。

「純文学」は**採らなかった**。作品の価値づけであって内容ではなく、
登録のたびに「これは純文学か」の判断を迫るため。
ジャンルに当てはまらない一般小説は「人間ドラマ」が既定の置き場になる。

### 2. 科学と技術の境界を定義し、テクノロジー → 技術・工学 に改名
- **科学・数学** = 世界を**理解する**営み(自然の法則・基礎研究)
- **技術・工学** = 人工物を**つくる**営み(応用・設計・製造)

抜けていた**化学**を補い、**半導体・電子工学 / 機械・材料工学 / エネルギー** を追加。
「Web・インターネット」は**Web・インフラ**に改め、クラウドやデータベースの実務書を収めた。

### 3. 言語学を哲学・思想 → 芸術・文化へ(言語・ことば)
ソシュールや日本語論を読む人が「哲学」を探すとは考えにくい。
同じ場所の「書物・読書論・文学論」と合わせ、**ことばと本をめぐる思索**のまとまりになる。

### 4. 歴史の地域軸を整理
「東洋史・中国史」は中国に偏り、インドや東南アジアの居場所がなかった。
**アジア・東洋史 / 欧米・西洋史 / 世界史・通史 / 考古・古代文明** に整理。
「世界史・通史」は『サピエンス全史』のような地域横断の通史の受け皿。

### 5. 欠落していた領域を補充
- 政治・社会 … **社会問題・福祉**(高齢化・介護・社会保障)
- 実用・生活 … **住まい・整理収納 / 美容・ファッション / ペット・園芸**
- 芸術・文化の「スポーツ」→ 実用・生活の**スポーツ・観戦**へ移動
  (他が表現芸術なので浮いていた)

### 6. 形式例外にも細分を用意
- **漫画**(8) … 小説と同じ内容の軸。読者層(少年/少女/青年)は市場の軸なので採らない
- **児童書・絵本**(5) … この枠自体が対象読者で定義されているので、
  内側を年齢と目的で分けるのは自分の軸に忠実

## 運用ルール(構造で解決しないもの)
- 建築 … 工学書は技術・工学、建築史・鑑賞は芸術・文化
- 介護 … 制度論は政治・社会、実務は実用・生活
- 資格書 … 分野ごとの該当細分へ(簿記→会計、IT資格→プログラミング)

## 既存データの移行

**書斎 →「タグを整理」に「まとめて統合する」ボタンが出ます。**

蔵書に旧タグがある場合だけ表示され、押すと全書籍が一括で新しい名前になります。

| 旧 | 新 |
|---|---|
| テクノロジー / 技術 | 技術・工学 |
| 東洋史・中国史 | アジア・東洋史 |
| 西洋史 | 欧米・西洋史 |
| 世界史 | 世界史・通史 |
| 古代・考古 | 考古・古代文明 |
| 社会問題 | 社会問題・福祉 |
| Web・インターネット | Web・インフラ |
| 半導体・ハードウェア | 半導体・電子工学 |
| ものづくり | ものづくり・製造 |
| スポーツ | スポーツ・観戦 |
| 言語学 | 言語・ことば |
| 文学・小説 / SF / ミステリ / 経済 / 投資 / エッセイ など初期タグ | 現行の対応タグ |

対応先がすべて実在することはテストで検証済み。統合しなくてもアプリは動く。
