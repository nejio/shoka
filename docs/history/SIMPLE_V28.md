# 書架 — 入力を簡単にする + 日付の編集 v28

## 1. 登録フォームを最小構成に

### これまでの問題
機能を足し続けた結果、1冊登録するのに
書名・状態3択・タグ(大分類→細分)・星・日付・感想・詳細欄…と並んでいた。
**初めて使う人が最初に見る画面としては過剰**だった。

原因は「入力できること」を全部フォームに出していたこと。
本来は「登録した後で足せること」を分けるべきだった。

### 変更後
既定で表示するのは**書名と状態だけ**。

```
[書影] 書名
[バーコード] [書名で検索] [検索]

この本は
[ 読んでいる ][ 読み終えた ][ 積んでおく ]

読み終えた日        ← 「読み終えた」を選んだ時だけ
[今日][昨日][一昨日][その他]

もっと詳しく入力する   ← 開いた人だけ

[      保存      ][やめる]
```

星・タグ・著者・ページ数・感想は「もっと詳しく」の中へ。
すべて**登録後に詳細画面から足せる**ので、最初に聞く必要がない。

## 2. 日付を言葉で選べるように

いちばん引っかかっていた日付入力を作り直した。

**[今日] [昨日] [一昨日] [その他]** のボタンを押すだけ。
カレンダーは「その他」を押した時だけ開く。

読み終えた本の大半は「今日」なので、ほとんどの場合ボタン1つで済む。
この部品は登録フォームと詳細画面の両方で使っている。

## 3. タグを任意に

タグ未設定でも登録できるようにした(「未分類」として扱われる)。
タグは書架の中核だが、**最初の1冊で必須にする必要はない**。
使ううちに自然と付けたくなればよい。

## 4. 【修正】読了日・読始日が編集できなかった

登録時にしか入力できず、後から直せなかった。
誤登録したら削除して作り直すしかない状態だった。
積んだ日は編集できるのに読了日ができないのは一貫性もなかった。

詳細画面の日付表示(「2026/08/10 読了」など)を**タップすると編集できる**。
読書中の本は読始日を、読了した本は読始日と読了日の両方を変更できる。
読始日が読了日より後になる指定は保存できないようにしてある。

