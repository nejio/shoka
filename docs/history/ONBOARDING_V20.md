# 書架 — オンボーディング v20

## 方針

「アイコンをハイライトして順に説明するツアー」は採用しなかった。理由:

1. **このアプリの難所は操作ではなく概念**。ボタンの位置は数回で覚えるが、
   「なぜ書斎があるのか」「積読は消化すべきタスクではない」は
   ハイライトでは伝わらない
2. **初回はデータが0冊**。空の画面を指して「ここに暦が出ます」と言っても記憶に残らない
3. **静かなアプリの思想と衝突**。起動直後に画面を覆ってタップを強いるのは
   このアプリが避けてきた押し付けがましさそのもの

代わりに **空状態の充実(D)** を土台に、**導入3枚(B)** で思想を伝える構成にした。

## 1. 導入3枚(初回のみ)

サインイン後、蔵書が0冊のときに一度だけ全画面で表示。

| 頁 | 意匠 | 伝えること |
|---|---|---|
| 1 | 暦のモザイク | 読んだ日が色で残る。続けるほど一年になる |
| 2 | 関心の地図 | 読まない本にも意味がある。積まれた群れが関心のかたち |
| 3 | 本棚 | 記録は右下のボタンから。バーコードで自動入力 |

- 「スキップ」でいつでも中断でき、その時点で既読になる
- レイアウトに一切依存しない独立コンポーネントなので、
  今後UIを変えても壊れない

## 2. 空状態の充実(常設)

各タブが空のとき、その画面に**何が現れるのか**と**なぜそれがあるのか**を語る。
スキップされず、常に正確で、保守コストがほぼゼロ。

| タブ | 見出し |
|---|---|
| 暦・統計 | 読んだ日が、色で残ります |
| 本棚 | 読み終えた本が、ここに並びます |
| 書斎 | 積んだ本が、関心の地図になります |
| 記録 | 最初の一冊から、歴史が始まります |

すべてに「右下の『記録』ボタンから本を追加できます」を添えた。
v19でFABに一本化した際に生じた発見性の問題を、ここで塞いでいる。

## 3. 既存ユーザーへの配慮

初回起動時に**蔵書が1冊以上あれば導入を出さず、既読として記録**する。
すでに使っている人に説明を見せない。

## 4. 表示済みフラグ

Firestoreの `users/{uid}` ドキュメントに `onboarded: true` を保存。
端末をまたいで一度きりになる(PCで見たらスマホでは出ない)。

将来の設定項目もここに置ける。

# ⚠ デプロイ前に必須の作業

**Firestoreルールの再公開が必要です。**

ユーザー設定を `users/{uid}` ドキュメントに保存するようになったため、
現在のルールのままだと権限エラーになります。

1. Firebaseコンソール → Firestore Database → ルール
2. `firestore.rules` の内容を貼り付け
3. 「公開」

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{uid} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
    }
    match /users/{uid}/books/{bookId} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
    }
  }
}
```

※ ルールを更新しなくてもアプリは動きます(設定の読み書きは失敗しても
　 例外を投げない設計)。ただし導入が毎回表示されてしまいます。

## デプロイ
`bundle.js?v=20` / `sw.js VERSION="v20"`。

## スモークテスト

導入は既に蔵書があると出ないため、確認するには:
Firestoreコンソールで `users/{自分のuid}` ドキュメントを削除 → 蔵書も空にする、
または別アカウントでサインインする。

- [ ] Firestoreルールを公開した
- [ ] 各タブを空の状態で開くと、それぞれ違う説明が出る
- [ ] すべての空状態に「右下の『記録』ボタンから」が出る
- [ ] 既存アカウント(蔵書あり)では導入が出ない
- [ ] 新規アカウントでは導入3枚が出る
- [ ] 「スキップ」で中断でき、再表示されない
- [ ] 「はじめる」まで進むと再表示されない
- [ ] 別端末で同じアカウントを開いても再表示されない
