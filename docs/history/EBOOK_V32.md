# 書架 — 電子書籍への対応 v32

電子書籍で使えなかった2点(バーコード・ページ数管理)を改善しました。

## 1. 進捗を％で記録できるように

**本ごとに進捗の単位**を持たせました。

- 電子書籍 … **％**(既定)
- 紙の本 … **ページ**(既定)

Kindleなどはページ番号を持たず%で位置を示すため、
ページ入力を強いるのは無理がありました。

進捗の入力欄・読書中カード・書斎のタイル・読書の足あとが、
すべて単位に応じた表示に変わります(「42％まで / 100％」「+12％」など)。
100％に到達すると自動で読了の記録に進みます。

### 統計への反映(判断が要ったところ)

％をそのままページ数として集計すると統計が壊れるため、次のようにしました。

| 条件 | 日別ページ数への計上 |
|---|---|
| 総ページ数を入力してある | **実ページ数に換算**(40%進んだ × 300p = 120p) |
| 総ページ数が不明 | **計上しない**(読書日にはカウントされる) |

電子書籍でも総ページ数を入れておけば、紙の本と同じ土俵で
ページ数の統計に乗ります。入れなくても読書日と読書暦には反映されます。

## 2. 登録時に「読む形式」を選べるように

「もっと詳しく」の中に **[紙の本] [電子書籍]** を追加しました。
電子書籍を選ぶとサービス(Kindle / 楽天Kobo / BOOK☆WALKER ほか)を指定でき、
進捗は自動的に％になります。

**バーコードについて**は、電子書籍に物理的なバーコードが無い以上、
読み取れるようにはできません。代わりに電子書籍を選んだ時点で
「電子書籍にはバーコードがありません。書名で検索してください」と案内し、
書名検索へ誘導します。書名検索は従来どおり書名・著者・ページ数・書影を取得します。

## 3. 後から単位を変えられる

詳細画面の保有状況欄に **進捗の記録単位** の切替を置きました。
ページ ⇄ ％ をいつでも変更でき、**記録済みの足あとは消えません**。

紙の本でもページ数を数えたくない人は％に、
ページ番号が表示される電子書籍はページに、と好みで選べます。

## 既存データについて
`progressUnit` が無い本は、保有状況から自動判定されます
(電子書籍なら％、それ以外はページ)。移行作業は不要です。

```

index.html
sw.js
```

## スモークテスト
- [ ] 本を追加 →「もっと詳しく」に [紙の本][電子書籍] が出る
- [ ] 電子書籍を選ぶとサービス選択とバーコードの案内が出る
- [ ] 電子書籍で登録した本の進捗入力が「％まで読んだ」になる
- [ ] 100を超える値を入れるとエラーになる
- [ ] 100％を入れると読了の記録に進む
- [ ] 読書の足あとが「42％まで +12％」と表示される
- [ ] 総ページ数を入れた電子書籍が、日別ページ数の統計に反映される
- [ ] 詳細画面から ページ ⇄ ％ を切り替えられる
