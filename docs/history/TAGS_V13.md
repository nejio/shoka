# 書架 — タグの刷新 v13

## 何が変わったか

### 1. 1冊に複数タグ(最大5つ)
『半導体戦争』を「経済・経営」「テクノロジー」「歴史」の3つで登録できる。
**先頭が主タグ**で、暦のマス・背表紙・一覧の色に使われる。
タグを選んだ順に並び、先頭には「主」の印が付く。

### 2. 軸を整理した新しい初期セット(12)
内容(主題)の一軸に統一。判型である「新書」は廃止、部分集合の重複も解消:

文学・小説 / SF・ファンタジー / ミステリ / エッセイ・紀行 / 歴史 / 政治・社会 /
経済・経営 / 金融・投資 / 科学・数学 / テクノロジー / 哲学・思想 / 実用・自己啓発

### 3. 自由入力
選択欄の下の「新しいタグを作る」で、その場で好きなタグを作れる。
一度使ったタグは次回から候補の先頭に出る(使用数の多い順)。

### 4. タグの整理(書斎タブ)
書斎タブ下部の「タグを整理」から:
- **名前変更** … 全書籍に一括反映
- **統合** … 既存のタグ名に変更すると自動的に統合(例: 旧「小説」→「文学・小説」)
- **削除** … 全書籍からそのタグを外す(本自体は消えない)

### 5. 関心の地図が複数タグを活かす
複数タグの本は、それぞれの群れに現れる。
冊数の合計は蔵書数を超えるが、関心の分布としてはこちらが正確。

### 6. 色は名前から自動決定
16色の落ち着いた色相から、タグ名のハッシュで安定して割り当てる。
タグを増やしても既存タグの色は変わらない。

## 既存データについて

**移行作業は不要**。旧形式(1冊1タグ)の本も自動で読み替えられる。
旧タグ(小説・新書・技術など)はそのまま残るので、「タグを整理」から
新セットへ統合するのがおすすめ:

| 旧 | 統合先の候補 |
|---|---|
| 小説 | 文学・小説 |
| SF | SF・ファンタジー |
| 経済 | 経済・経営 |
| 投資 | 金融・投資 |
| 技術 | テクノロジー |
| エッセイ | エッセイ・紀行 |
| 新書 | (判型なので削除、または内容に応じて) |

## デプロイ
`bundle.js?v=13` / `sw.js VERSION="v13"`。上書き → `npm run build` → 3ファイル。
