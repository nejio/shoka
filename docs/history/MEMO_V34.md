# 書架 — 読書メモと全体検索 v34

## 前提として直したこと

これまでの `note` は**1冊につき1つ、読了時に書く一行の感想**でした。
読みながら溜まっていく記録ではないため、これを一覧しても中身が乏しい。
そこでメモの仕組みから作り直しました。

## 1. 進捗にひとことメモを付けられるように

進捗を記録するときに、メモを添えられます。

```
8/10  p.120まで  +40p
      第3章の議論が鋭い
8/12  p.185まで  +65p
      中盤が冗長
```

**読みながらメモが自然に溜まります。** 空欄なら何も残らないので、
書きたいときだけ書けば足あとは汚れません。
詳細画面の足あとから、後で書き足すことも編集することもできます。

感想欄も複数行に変えました(従来は改行できませんでした)。

## 2. 「覚書」タブ(5つ目)

タブを **暦 / 本棚 / 書斎 / 覚書 / 記録** の5つにしました。
「暦・統計」を「暦」に短縮して幅を確保しています。

覚書タブには、**進捗メモと感想が時系列で並びます**。月ごとの見出し付き。
各メモには書名・日付・どこまで読んだ時点かが添えられ、
タップするとその本の詳細が開きます。

メモが読了・読書中・積読のすべてに散らばっており、
**どのタブも所有者になれない**ため、独立した場所を与えました。

## 3. 全体検索(ヘッダーの虫眼鏡)

**書名・著者・タグ・メモを横断**して検索します。

メモ限定にしなかったのは、利用者は「メモを検索している」のではなく
**「あの話どこで読んだっけ」を探している**からです。
手がかりが書名のときも、うろ覚えの一節のときもあるので、対象を分けると
外したときに「無い」と誤解します。

- 空白区切りで複数語を指定でき、**すべて含む本**だけが出ます
- **一致したメモの一節**が結果に表示されます(長い場合は前後を切り出し)
- 書名に一致した本が上位に並びます
- 全データは端末上にあるので、**オフラインでも即座に動きます**

## デプロイ
