# 書架 — Phase 2(書誌取得・バーコード)追加分

## 何が増えたか

記録フォームの書名欄の下に「書誌取得」ブロックを追加:
- **📷 バーコード** — カメラで本の裏のバーコードを読み取り、ISBNから書誌を自動取得
- **ISBN・書名で検索** — 数字を入れればISBN照会、文字を入れればタイトル検索(候補から選択)

取得できる情報: 書名 / 著者 / 総ページ数 / 書影(表紙画像) / タグ(自動推定・修正可)

書誌ソース: openBD(国内書籍に強い)→ 見つからなければ Google Books で補完。

## 動作の前提

- **HTTPS必須**: カメラはHTTPS(=GitHub Pages公開URL)でのみ動作。localhostも可。
- **バーコードは実機検証**: PCにカメラがなければスマホの公開URLで確認してください。
- **対応の内訳**:
  - Android Chrome: 端末内蔵の BarcodeDetector を使用(追加ダウンロードなし・高速)
  - iOS Safari 等: ZXingライブラリを**その場で読み込み**(初回スキャン時のみ数百KB)。
    普段のアプリ本体サイズには影響しません。
- **978/979フィルタ**: 日本の書籍バーコードは上下2段。価格情報の下段(192始まり)は
  自動で無視し、ISBN(978/979)だけを拾います。

## デプロイ

Phase 4と同じ手順。今回 `bundle.js?v=3` / `sw.js VERSION="v3"` に更新済み。
再ビルドして bundle.js / index.html / sw.js を再アップロードしてください。

```bash
npm run build
# GitHubへ bundle.js, index.html, sw.js を再アップロード
```

新規ファイル(src/)はビルドに取り込まれるので、アップロードは成果物のみでOK。

## スモークテスト(実機)

- [ ] 「ISBN・書名で検索」に書名を入力→候補が出る→選ぶとフォームに反映
- [ ] 手持ちの本のISBN(13桁)を入力→書名・著者・ページ・タグが入る
- [ ] 📷ボタン→カメラ許可→本の裏バーコードを枠に→自動で書誌が入る
- [ ] 推定タグが違ったら手動で選び直せる
- [ ] 書影サムネイルが表示される
- [ ] 取得後に保存→通常通り記録される

## トラブルシューティング

| 症状 | 対処 |
|---|---|
| カメラが起動しない | HTTPS URLか確認。ブラウザのカメラ許可を確認 |
| バーコードを認識しない | 明るい場所で、バーコード全体を枠内に。手ブレを抑える |
| 書誌が見つからない | 洋書や新刊は穴があることあり。手入力で補完 |
| iOSでスキャンが重い | 初回のみZXing読込。2回目以降は高速 |
