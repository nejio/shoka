# 書架 — 書名検索の強化 v33

## 解こうとした問題

電子書籍にはバーコードが無いため書名検索が主役になりますが、
**著者名が打てない**という問題が残っていました。

- 漢字が読めない(劉慈欣)
- 表記が分からない(ハラリ / Harari)
- そもそも思い出せない

著者名の入力欄を足すだけでは、**打てる人には便利、打てない人には無意味**です。
必要なのは「打たずに指定できる手段」でした。

## 1. 検索結果から著者を選べるように(本命)

書名で検索すると、**結果に含まれる著者がチップで並びます**。

```
著者で絞る: [劉慈欣 3] [別の人 1]
```

タップするとその著者の本だけに絞られます。
**読めなくても、見て選べます。** これが打てない問題への直接の答えです。

## 2. 蔵書にいる著者を候補に出す

同じ著者の本をもう1冊登録する場面では、
**すでに蔵書にいる著者**が候補として出ます。書名の一部からも引けます。

```
蔵書の著者: [沢木耕太郎] [塩野七生]
```

一度登録した著者は、二度と打つ必要がありません。

## 3. 著者名の入力欄(任意)

打てる人のために、検索欄の下に著者名の入力欄を常時表示しました。
書名と著者は**別々の条件**として検索に渡すため、
単純に連結するより精度が上がります(`intitle:` と `inauthor:`)。

書名が思い出せず著者だけ分かる場合は、**著者名だけでも検索できます**。

## 4. 候補一覧に出版社と出版年

文庫化や新装版の見分けがつくよう、候補に出版社と出版年を添えました。

```
三体
劉慈欣 ・ 早川書房 2019
```

**出版社の入力欄は作りませんでした。** 利用者が出版社を正確に
覚えていることは稀で(「講談社」か「講談社文庫」か)、曖昧な入力は
絞り込みどころか該当ゼロを招きます。打たせるより見せる方が確実です。

## デプロイ
`bundle.js?v=33` / `sw.js VERSION="v33"` / 設定画面 `v33`。

```
bundle.js
index.html
sw.js
```

## スモークテスト
- [ ] 検索欄の下に「著者名(任意)」が出ている
- [ ] 書名で検索すると「著者で絞る」のチップが出る(2人以上いる場合)
- [ ] チップをタップすると結果が絞られる。もう一度押すと解除される
- [ ] 候補に出版社と出版年が表示される
- [ ] 著者名だけを入れても検索できる
- [ ] 蔵書にある著者の本を書名で検索すると「蔵書の著者」が出る
- [ ] 蔵書の著者をタップすると著者欄に入る
