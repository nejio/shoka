# 書架 — 用語・タグ・評価の修正 v29

## 1. 状態の用語を元に戻した

v28で「読んでいる/読み終えた/積んでおく」に変えたのは、
**やり過ぎでした**。指示は「複雑な使いにくさの修正」であって、
用語を平易にすることではありませんでした。

記録タブの見出し(読書中/読了)とも食い違っており、一貫性を欠いていました。

**[ 積読 ][ 読書中 ][ 読了 ]** に統一しました。
日付のラベルも「読了日」「読始日」に戻しています。

## 2. タグを常に表示する(登録は任意のまま)

v28で「もっと詳しく」の中に隠したのは誤りでした。
タグは関心の地図の軸であり、**自分の読書の偏りに気づくための仕掛け**です。
隠してしまうとその意図が失われます。

登録フォームに常に表示し、**付けなくても保存できる**形にしました。
「任意・あとから変えられます」と添えてあります。

## 3. 星を後から編集できるように

詳細画面の星をタップすると評価を変更できます。
未評価の本には「評価する」と点線のボタンが出ます。
**同じ星をもう一度押すと未評価に戻せます**。

## 4. 既定で星3になっていた件

**設計上の根拠はありませんでした。**
バリデーションで「未指定なら3」という既定値を置いていただけです。

これは利用者が付けていない評価を勝手に作ってしまう挙動なので、
**未評価(星なし)を許容する**ように直しました。
評価せずに登録した本には星が表示されません。
