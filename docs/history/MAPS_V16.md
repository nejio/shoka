# 書架 — 二つの地図 v16

## 1. 【是正】読み始めた本が地図から消える問題

積読を読み始めると `status` が変わり、関心の地図から消えていた。
**いま読んでいる本は、積んである本より強い「現在の関心」**のはずで、
思想と矛盾していた。

### 修正
関心の地図の対象を **積読 + 読書中** に拡張。
読書中の本は**金の縁取りと進捗バー**で区別される。
積読が静かに積まれている中で、読書中の本だけが光っている状態。

※「今日の一冊」と読了時の想起は、**積読のみ**を対象のまま維持。
　これらは「忘れている本を思い出させる」仕掛けであり、
　いま読んでいる本は忘れていないため。

## 2. 【新機能】知識の地図(本棚タブの表示切替)

本棚タブに **[時系列で見る] [主題で見る]** の切替を追加。
「主題で見る」が知識の地図。

### なぜ冗長ではないか

二つの地図は違う問いに答えている:

| | 対象 | 意味 | 性質 |
|---|---|---|---|
| **書斎 / 関心の地図** | 積読 + 読書中 | どこへ向かっているか | フロー・未来向き・変動が速い |
| **本棚 / 知識の地図** | 読了 | 何を積み上げてきたか | ストック・過去の累積・変動が遅い |

損益計算書と貸借対照表の関係。同じ蔵書を見ていても、別の書類が要る。

これまでのアプリは「いつ読んだか」(読書暦)、「何冊読んだか」(本棚)、
「その期に何を読んだか」(四半期構成=これもフロー)には答えられたが、
**「私は何について詳しくなったのか」に答える画面がなかった**。

### なぜ独立タブにしないか

読了本は既に本棚に住んでいるので、同じ本を別の軸で見るだけ。
そもそも**現実の本棚は本来ジャンル順**で、時系列の棚のほうが特殊。
主題別の棚こそ「本棚」の原義に近い。

### 全期間 / 直近1年の切替

読了が数百冊に達すると知識の地図は動かなくなり、見る理由が薄れる。
「直近1年」に切り替えると、いま伸びている分野が分かる。
全期間=蓄積の全体像、直近1年=成長の方向。

## 役割の整理

- **書斎** = これから・いま(積読+読書中)。見送りは退避場所 → **未来**
- **本棚** = 読み終えた本。時系列でも主題でも見られる → **過去**

## 実装の整理

地図の描画を `components/tagmap.jsx` に共通化(分布バー・階層表示・タイル)。
集計は `lib/study.js` の `buildTagMap(list)` を共通の核とし、
`buildStudyMap`(積読+読書中)と `buildKnowledgeMap`(読了・期間指定可)が
それを呼ぶ構造。どちらの地図も本は1冊1回しか現れない。
