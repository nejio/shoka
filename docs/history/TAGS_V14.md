# 書架 — タグ分類の再設計 v14

## 設計の根拠

**日本十進分類法(NDC)を読書記録向けに改変**した二層構造。
前回の即興的な分類を廃し、基準を明示した。

NDCからの意図的な改変:
| 改変 | 理由 |
|---|---|
| 9文学を「小説」と「エッセイ・紀行」に分割 | フィクションか否かが読書記録では最重要 |
| 0総記の情報科学 + 5技術 → テクノロジー | 現代では計算機と工学は地続き |
| 3社会科学から経済を独立 | 一般読者の関心量が大きい |
| 6産業を経済・経営に吸収 | 個人の読書では産業論と経営書は不可分 |
| 8言語 → 言語学は哲学・思想、語学は実用・生活 | 学問と実用を分ける |
| 0総記を廃止 | 一般読者が読む機会がほぼない |

## 構造

**第一階層: 大分類10 + 形式例外2**
小説 / エッセイ・紀行 / 歴史 / 政治・社会 / 経済・経営 / 科学・数学 /
テクノロジー / 哲学・思想 / 芸術・文化 / 実用・生活 ＋ 漫画 / 児童書・絵本

**第二階層: 細分69個**(各大分類に5〜8個)

### 前回からの修正

1. **軸のねじれを解消** … 「海外文学」(地域軸)「純文学」(価値軸)を廃止。
   小説の細分は内容ジャンルのみに統一。海外作品を区別したい場合は
   自由タグ(「海外」「翻訳」など)で足せる。
2. **人文の補強** … 民俗学・文化人類学(政治・社会へ)、言語学(哲学・思想へ)を追加。
3. **書物論の独立** … 「読書論」を実用・生活から外し、
   芸術・文化の「書物・読書論・文学論」へ。読書記録アプリにとって
   「本についての本」は固有の意味を持つため。
4. **心理学の切り分け** … 学術的心理学は科学・数学の「心理・脳科学」に統合
   (旧・脳科学と重複していた)。実用的なコミュニケーション本等は
   実用・生活の「自己啓発」へ。
5. **形式軸の例外を明示** … 漫画・児童書は内容軸ではないが、
   1冊あたりの所要時間・ページ数が桁違いで**統計を歪める**ため、
   意図的な例外として第一階層に置く。

## 使い方(段階的表示)

1. まず「分野」から大分類を選ぶ(12個だけ表示)
2. 選んだ分野の**細分だけ**がその下に現れる(小説を選んだ人に
   プログラミングの細分は出ない)
3. 細分を選ぶと親の大分類が自動で付く(地図の整合性のため)
4. 過去に自作したタグは「自作のタグ」欄に再表示される

目に入るのは常に 12個 + 5〜8個。69個の細分があっても画面は破綻しない。

### 分類例
| 本 | タグ |
|---|---|
| 三体 | 小説 + SF・ファンタジー |
| 吾輩は猫である | 小説 |
| 成瀬は天下を取りに行く | 小説 |
| ライトノベル | 小説 + ライトノベル |
| 半導体戦争 | テクノロジー + 半導体・ハードウェア + 企業史・産業論 |
| 積読こそが完全な読書術である | 芸術・文化 + 書物・読書論・文学論 |
| 中国「造車新勢力」の衝撃 | 経済・経営 + 企業史・産業論 (+自由タグ「中国」) |

## 既存データ

移行不要。旧タグはそのまま残るので、書斎の「タグを整理」から統合を推奨:

| 旧 | 統合先 |
|---|---|
| 小説 / 文学・小説 | 小説 |
| SF | SF・ファンタジー |
| 経済 | 経済・経営 |
| 投資 | 金融・投資 |
| 技術 | テクノロジー |
| エッセイ | エッセイ・紀行 |
| 新書 | 内容に応じた大分類へ(判型なので廃止) |

## デプロイ
`bundle.js?v=14` / `sw.js VERSION="v14"`。
