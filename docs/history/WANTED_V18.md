# 書架 — 気になる本 v18

## 追加内容

保有状況に「**気になる本**」(まだ持っていない本)を追加。
書評で見かけた本、別の本で言及されていた本を、買う前に書き留められる。

呼び名は「未所持」ではなく「気になる本」。在庫管理の語彙を避け、
買う義務を感じさせないため。

## 他の保有状態との違い

気になる本は3点で他と異なるので、扱いを分けている。

### 1. 登録時に分かっている唯一の保有状態
他の保有状況は詳細画面のみで設定するが、気になる本だけは
**登録フォームにチェックボックス1つ**を出す(積読を選んだときのみ表示)。
「積んだ日」のラベルも「書き留めた日」に変わる。

### 2. 頻繁に変わる
- 詳細画面に「**この本を入手した**」ボタン
- 気になる本を**バーコードで登録し直すと自動で入手済みになる**
  (買ってきてスキャンする流れ)
- 「読んでいる」で登録すると入手済み+読書中に自動遷移
  (持っていない本は読めないため)

### 3. 際限なく増える
欲しい本のリストには上限がないため、本来の積読が埋もれないよう分離した。

| | 扱い |
|---|---|
| 地図への表示 | 含める。**破線の枠**で描く |
| 冊数の表記 | 「手元に 24冊 ・ 気になる 12冊」と分けて数える |
| 分布バー | **手元にある本のみ**で構成(混ぜると分布が歪む) |
| 今日の一冊 | **対象外**。「持っているのに忘れている本」の仕掛けなので |
| 読了時の想起 | **対象外**。「買え」という催促になるため |
| 表示切替 | 「気になる本も地図に表示する」トグル(既定ON) |

## 視覚表現

透明度ではなく**破線の枠**を使う。
透明度は「重要度が低い・無効」と読めるが、破線は「まだ実体化していない」と読める。
気になる本は、まだ生活に現れていない本である。

- 読書中 = 金の実線の縁 + 進捗バー
- 気になる本 = 灰色の破線の枠
- 積読 = 枠なし

## 方針として決めたこと

**購買導線は作らない**。書店リンク・価格表示・セール通知などは実装しない。
ウィッシュリストは購買行動と直結するため、放置すると
このアプリが避けてきた方向(商業的な催促)に流れる。
「気になった本を書き留める」までに留める。

## デプロイ
`bundle.js?v=18` / `sw.js VERSION="v18"`。

## スモークテスト
- [ ] 登録フォームで積読を選ぶと「まだ持っていない(気になる本)」が出る
- [ ] チェックすると日付ラベルが「書き留めた日」に変わる
- [ ] 書斎の地図に破線の枠で表示される
- [ ] 冊数が「手元に◯冊 ・ 気になる◯冊」と分かれている
- [ ] 分布バーの合計に気になる本が含まれていない
- [ ] 「気になる本も地図に表示する」を外すと消える
- [ ] 詳細に「この本を入手した」が出て、押すと破線が消える
- [ ] 同じ本をバーコードで登録し直すと入手済みになる
- [ ] 「今日の一冊」に気になる本が出ない
