# 書架 — 歯車アイコンの作り直し v24

## 問題
v23の歯車は「中心の円から直線を8本放射させる」だけの形だったため、
**太陽にしか見えなかった**。歯車の「歯」を表現できていなかった。

## 修正
歯の外形を数値計算で生成し直した。

- 8歯 / 歯先の半径 9.4 / 歯底の半径 6.9(歯の深さ 2.5)
- 歯先の角度幅 18°、斜面 6.5°、歯底 12° … 歯と谷の比率が自然に見える配分
- 中心の穴は半径 3.4

放射する直線ではなく、**歯の輪郭を一筆で描いた閉じたパス**になっている。

## デプロイ
`bundle.js?v=24` / `sw.js VERSION="v24"`。

**前回アップロードし忘れた `fonts/` フォルダも、今回まとめてアップロードしてください。**

アップロードするもの:
```
index.html
bundle.js
sw.js
fonts/          ← 前回未アップロード
```
